KIT PARA GERAR INSTALADOR DO ROBLOX AUTOFARM v11

1) Copie estes tres arquivos para a pasta do projeto (ao lado de main.py):
   - COMPILAR_APLICATIVO.cmd
   - AutoFarm_Instalador.iss
   - TERMOS.txt
2) Execute COMPILAR_APLICATIVO.cmd no Windows.
3) Teste dist\RobloxAutoFarm\RobloxAutoFarm.exe
4) Instale o Inno Setup do site oficial https://jrsoftware.org/isdl.php
5) Abra AutoFarm_Instalador.iss no Inno Setup e clique em Build > Compile.
6) O instalador final sera: instalador\Roblox_AutoFarm_v11_Setup.exe

IMPORTANTE: Tesseract OCR precisa estar instalado no Windows para o reconhecimento de Candies.
O PyInstaller NAO inclui automaticamente tesseract.exe. O projeto busca o Tesseract no PATH e pastas usuais.
O Windows Smart App Control pode bloquear EXEs sem assinatura confiavel. Um instalador nao elimina isso.
Para distribuicao sem bloqueios de reputacao, providencie assinatura digital confiavel dos binarios e do instalador.
Nao desative protecoes do Windows para tentar contornar bloqueios.

O kit apenas configura a compilacao e o instalador; ele nao contem o codigo-fonte do AutoFarm.
